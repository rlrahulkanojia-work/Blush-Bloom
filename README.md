# Blush & Bloom - Makeup Services Website

![Blush & Bloom](https://source.unsplash.com/random/1200x600/?makeup,beauty)

## Overview

Blush & Bloom is a professional website for a premium makeup services business. The site showcases the company's portfolio, services, team, and provides easy ways for clients to get in touch and book appointments.

**Tagline:** "By Neha Gupta"

## Features

- **Responsive Design:** Fully responsive layout that works on mobile, tablet, and desktop devices
- **Modern UI:** Clean, elegant interface with smooth animations and transitions
- **Portfolio Gallery:** Categorized showcase of makeup work with filtering options
- **Service Packages:** Detailed information about services and pricing
- **Team Profiles:** Information about the founder and team members
- **Blog Section:** Beauty tips, tutorials, and product recommendations
- **Contact Forms:** Easy-to-use forms for inquiries and bookings
- **Interactive Elements:** 
  - Portfolio filtering
  - Service tab navigation
  - FAQ accordions
  - Form validation
  - Image galleries
  - Mobile navigation

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of HTML, CSS, and JavaScript (for developers)

### Installation

1. Clone the repository or download the ZIP file
   ```
   git clone https://github.com/yourusername/blush-and-bloom.git
   ```

2. Navigate to the project directory
   ```
   cd blush-and-bloom
   ```

3. Open `index.html` in your browser to view the website locally

## Deployment

The website can be deployed using several free hosting options:

### GitHub Pages

1. Create a GitHub repository
2. Upload all website files
3. Enable GitHub Pages in repository settings
4. Access your site at `https://yourusername.github.io/repository-name/`

### Netlify

1. Create a Netlify account
2. Drag and drop your website folder or connect to GitHub
3. Configure form handling by adding `data-netlify="true"` to forms
4. Access your site at the provided Netlify subdomain

### Vercel

1. Create a Vercel account
2. Import your project from GitHub or upload directly
3. Configure deployment settings
4. Access your site at the provided Vercel subdomain

### Firebase Hosting

1. Create a Firebase account
2. Install Firebase CLI: `npm install -g firebase-tools`
3. Login and initialize: `firebase login` and `firebase init`
4. Deploy your site: `firebase deploy`
